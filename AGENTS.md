# Haidra standards index

Standards for anyone, human or agent, working in a Haidra-Org repository. Each is prescriptive; deviate where the
result is better for it and say why in review.

- [docs/meta/copy.md](docs/meta/copy.md): user-facing text in products, including tutorial, guide and help copy, and
  the `caption`, `why` and `notes` strings in the
  [haidra-param-sweeps](https://github.com/Haidra-Org/haidra-param-sweeps) specs, which reach readers unchanged.
- [docs/meta/documentation.md](docs/meta/documentation.md): the contributor `docs/` tree, Diátaxis organisation,
  front matter and prose rules.
- [docs/meta/python.md](docs/meta/python.md): Python style, typing and docstrings.
- [docs/meta/pull_requests.md](docs/meta/pull_requests.md): pull request text.

Repositories that vendor this one as a submodule (usually at `docs/haidra-assets`) treat these as governing.
